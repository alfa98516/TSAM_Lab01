# TSAM Lab 1 - UDP Port Scanner

To compile the program, open up your desired command line tool and type in:

```Bash
make
```

Then to run the program you type in:

```Bash
./scanner <IPADDR> <LOWPORT> <HIGHPORT>
```

Where IPADDR is the ip address you want to scan, LOWPORT is the first port you want to scan and HIGHPORT is the last port you want to scan.
LOWPORT and HIGHPORT are a range.
